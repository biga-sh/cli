**biga CLI** lets you share your local codebase through a live, read-only browser link. Share what you're working on without asking someone to install your development environment or join a screen-sharing call.

## Get started

### Install

**macOS and Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/biga-sh/cli/main/install.sh | sh
```

**Windows PowerShell**

```powershell
irm https://raw.githubusercontent.com/biga-sh/cli/main/install.ps1 | iex
```

Review the installation script before executing it. For supported platforms, alternative installation methods, verification, and troubleshooting, see the [installation documentation](https://website-vw4l.vercel.app/docs).

### Share a project

From your project directory, run:

```bash
biga start
```

Follow the CLI output to open or share your session link.

Useful commands:

```bash
biga status
biga list
biga open
biga stop
```

Check the [CLI documentation](https://website-vw4l.vercel.app/docs) for command options and configuration details.

## What you can do

- **Share a live codebase** — let others inspect your work in their browser.
- **Stream updates** — keep viewers up to date as your code changes.
- **Keep viewing read-only** — share code without giving viewers access to your local machine.
- **Control what gets shared** — configure exclusions for files that should not be included.
